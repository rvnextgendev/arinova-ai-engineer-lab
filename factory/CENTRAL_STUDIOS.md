# Central studio pilot
Run policy_studio.py and open /factory on port 8790. Register, configure, plan, generate, develop (prepare isolated copy), execute (OpenHands Docker worker), quality (Docker unit tests), approve (tested digest), deliver (local ZIP). Build the worker with docker build -t arinova-openhands-worker -f factory/Dockerfile.openhands factory. Pre-pull python:3.11-slim. Configure local Ollama and existing worker environment as documented.
Run python -m unittest discover -s factory -p "test_central*.py" -v.
The end-to-end regression uses mocked OpenHands and quality workers; it is not live model or Docker validation. The real quality runner uses a read-only frozen snapshot, network disabled, non-root user and resource limits. Unit tests alone do not prove security or business correctness. Existing policy delivery copies only its allowlisted files. The ZIP includes the tested workspace, requirements, architecture and evidence, not a remote Git push. The project generator remains a generic starter. Local SQLite serializes transitions and holds a write lock during long tasks. No durable background worker, authenticated approval, independent trusted acceptance suite, full SDK wiring, or production certification. Use only fictional data and trusted local code. Existing studios remain available.
