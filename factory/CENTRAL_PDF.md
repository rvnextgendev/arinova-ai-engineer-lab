# Central PDF and Agent Studio
Install requirements-studio.txt. Configure ARINOVA_POLICY_DSN for a running PostgreSQL with pgvector, ARINOVA_OLLAMA_URL and ARINOVA_AGENT_MODEL for a local tool-capable Ollama model. Pull nomic-embed-text. Start python factory/policy_studio.py, generate HR and IT at /factory/demo, then visit /factory/pdf.
Upload different fictional text PDFs to each project. Verify document inventory and ask questions in rag, langgraph, deep, mcp and compare modes. Verify tool events and citations manually. Ask an HR-only question in IT and check abstention; vector retrieval may still return irrelevant excerpts, so abstention is not guaranteed. Upload same filename to both and verify each inventory remains separate. Repeat with two HR projects to verify project-level rather than department-level namespaces.
No actual tenant authentication, OCR, independently verified citations, or guaranteed agent tool use. Direct RAG streams start/end only; agent callbacks stream model/tool events. Compare judge is advisory. No live runtime tests performed. Generated customer standalone applications do not automatically include this central server integration.
