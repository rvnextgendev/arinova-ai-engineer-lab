# Reference workflows
Open /factory, select Reference Workflows, click Generate all four reference projects. Select each generated project in the common header. Acquisition: load sample, extract; expect 4 rows, 2 accepted, 1 duplicate, 1 invalid. Invoice: extract sample, approve using INV-001; repeat extraction to see duplicate rejection. Commerce: catalog, add SKU-1 quantity 2, checkout; expect 1000 cents and simulated_no_charge. Enterprise: register EMP-001, request 2 days, copy request ID from state, approve using that ID. View saved state after switching projects. Admin can do all actions; assigned developer executes business actions, approver approves.
Run python -m unittest discover -s factory -p test_reference_workflows.py -v.
Generated reference source supports JSON stdin CLI and Dockerfile; not a standalone web application. Central workflow state is SQLite, independent of generated source edits. Existing OpenHands and release workflows require further integration validation for these templates. No live scraping, OCR, LLM invoice extraction, real payments, or .NET implementation. No runtime tests executed here.
