OpenHands Coding Studio
Guided workflow — checklist is manual, not agent execution telemetry.
  1. Run docker info and ollama list in PowerShell. Docker Desktop must be running.
  2. Use Software Factory above. Enter the exact generated project name below.
  3. Describe functionality, acceptance criteria and constraints.
  4. Run the prepared PowerShell command from the repository root. Keep the terminal open.
  5. In Agent Canvas choose an Ollama-compatible provider, model llama3.2:latest and host http://host.docker.internal:11434 (append /v1 for OpenAI-compatible configuration).
  6. Open Agent Canvas, select the mounted /projects workspace and paste the prepared task. Review any permission requests.
  7. Review files in the agent-workspaces directory printed by the launcher. Do not copy secrets into it.
  8. From the reviewed workspace run python -m unittest -v after inspecting the generated code. Prefer an isolated test environment.
  9. Review code, test output and security implications. Record approval only after inspection.
  10. Manually copy approved changes into the customer project and use Git diff before committing. No automatic merge.
  11. Stop the Docker launcher with Ctrl+C. Review workspace files remain on disk.
