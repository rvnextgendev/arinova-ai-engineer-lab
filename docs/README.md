# Offline handbook PDF

[**Open AriNova AI Architect — 48-page Offline Handbook**](AriNova_AI_Architect_Offline_Handbook.pdf)

This edition preserves the written material and annotated code extracted page by page from the original 48-page handbook. It was **reflowed as a searchable, text-first PDF** for direct GitHub browser viewing. The layout/typography and special Unicode glyphs may differ from the original PDF.

For an exact, executable Python source, use [the annotated script](../learning/arinova_architect_master_annotated.py). The code is authoritative over PDF formatting/transliteration.

## Coverage

Document ingestion, chunking, embeddings, pgvector, hybrid retrieval and reranking; Ollama and LangGraph; identity, tenant isolation, RLS, input guardrails; evaluations and LLM judge; observability, reliability, cancellation and replay; MCP, approval, feedback and LoRA; offline tests and Azure mapping.

## Production-readiness warning

The material is for **personal education and local practice**. Several integrations are optional or conceptual; distributed operational guarantees, hosted API, secrets, deployment automation, OCR/layout parsing, advanced evaluation and full integration tests remain open work.
